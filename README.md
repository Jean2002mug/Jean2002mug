### Featured projects

#### 🌌 [Gravity Calculator](https://github.com/Jean2002mug/Gravity-Calculator) · [Live app](https://gravitykalkilateri2023.com/)

A deployed physics application with **nine gravitational and orbital calculations**, celestial-body data, and saved calculation history. Built with **React + TypeScript**, **Node.js/Express**, **Python/FastAPI**, and **PostgreSQL**.

#### ✈️ [AirSeparator](https://github.com/Jean2002mug/AirSeparator)

An educational aircraft-separation simulator featuring a **C++20 calculation engine**, HTTP API, and **React/TypeScript map interface**. Supports configurable separation thresholds, pairwise checks for multiple aircraft, automated tests, and a **Docker Compose** setup. *Simulation only; not for operational aviation use.*

#### 🎹 [Sightreading App](https://github.com/Jean2002mug/Sightreading-app) · [Windows release](https://github.com/Jean2002mug/Sightreading-app/releases)

An interactive music sight-reading desktop app built with **Java 21 and JavaFX**. Includes note/chord exercises, **MIDI and computer-keyboard input**, difficulty settings, and an installable Windows package.

#### 🗂️ [CSV Library in C](https://github.com/Jean2002mug/csv-parser-c)

A **C library for reading and writing CSV records** with dynamic memory allocation and variable-length fields. A hands-on exercise in file handling, parsing, and memory management.
